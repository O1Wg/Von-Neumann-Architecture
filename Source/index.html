Von neumann architecture

The Von Neumann architecture is a computer architecture model that describes a system where the computer's memory and processing units are separate, allowing for the storage of both data and instructions in the same memory space. This architecture is named after the mathematician and physicist John von Neumann, who first proposed the concept in the 1940s.
