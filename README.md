# Von-Neumann-Architecture-
A website that explains Von Neumann Architecture in a basic simplified way using html/css/js
```text
+---------+        +-------------------------------+        +----------+
|  INPUT  | -----> |              CPU              | -----> |  OUTPUT  |
+---------+        |  +-------------------------+  |        +----------+
                   |  |      Control Unit       |  |
                   |  +-------------------------+  |
                   |  |  Arithmetic Logic Unit  |  |
                   |  +-------------------------+  |
                   |  |        Registers        |  |
                   |  +-------------------------+  |
                   +---------------+---------------+
                                   ^
                                   |   bus (data / address / control)
                                   v
                   +-------------------------------+
                   |            MEMORY             |
                   |   (program + data together)   |
                   +-------------------------------+
```


# concept idea:

making a simple website that explains Von Neumann using text and drawings to simplify it and make it easier to understand.
# Why make it?

The reason is to learn and teach it to others.
